# diagprint v0.8.0

Release date: 2026-09-17

diagprint v0.8.0 turns the completed M4, E1, and M5 development trains into one
coherent public release.

## Published package matrix

```text

diagprint-lsp          0.8.0

diagprint-otel         0.8.0
diagprint-test         0.8.0
```

`diagprint-bridge` and `diagprint-error-stack` are new in v0.8.

## Diagnostic graph and forensics

v0.8 adds typed diagnostic relationships, separate evidence provenance,
deterministic graph verification, cycle-safe traversal, causal-cascade analysis
over recorded causal edges, and `diagprint graph`.

The evidence doctrine remains explicit:

```text
provenance != causation
association != causation
```

## Git provenance and blame

v0.8 adds `diagprint.forensics.git-provenance/v1` and `diagprint blame`.

History runs can be bound to exact Git commit/tree/parent identities. Forensic
output verifies history and Git identity before presenting repository context.
Repository association is evidence, not proof of causation.

## Ecosystem interoperability

The new `diagprint-bridge` SDK centralizes reusable adapter mechanics,
canonical logical identity, report/graph assembly, builder-scoped construction
handles, and shared validation while remaining ecosystem-neutral.

The new `diagprint-error-stack` crate supports single and grouped reports,
typed context mapping, stable source-frame traversal, source-chain relationship
evidence, and privacy-aware attachments. Printable attachment text is omitted
by default; opaque attachment values are never exported.

## Remediation evidence and replay

v0.8 adds:

```text
diagprint.remediation.evidence/v1
diagprint.forensics.remediation-replay/v1
```

and:

```text
diagprint replay <HISTORY> <FINGERPRINT>
diagprint history replay <HISTORY> <FINGERPRINT>
diagprint history remediation-verify <HISTORY>
```

Replay is read-only. A later reappearance is labeled a regression after
verified remediation only when declared verification passed, the diagnostic
was observed resolved immediately afterward, and the same canonical
fingerprint later reappeared.

Even then:

```text
remediation-caused-resolution: NOT ESTABLISHED
recurrence-root-cause: NOT ESTABLISHED
git-causation: NOT ESTABLISHED
```
